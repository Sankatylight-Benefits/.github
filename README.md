# Sankaty Light Benefits

> **Innovative Employee Benefits. Better Healthcare Outcomes. Stronger Organizations.**

Welcome to the official GitHub repository for **Sankaty Light Benefits**.

This repository contains the source code, documentation, and assets for **https://sankatylight.com**, the official website for Sankaty Light Benefits and its flagship employee benefits solution, **ExecSelect™**.

---

## About

Sankaty Light Benefits helps employers enhance their employee benefits strategy through innovative, tax-advantaged supplemental health benefit solutions.

Our flagship program, **ExecSelect™**, is a fully insured excepted benefits plan designed to help employers recruit, reward, and retain key employees by reimbursing eligible out-of-pocket healthcare expenses not covered by their primary medical insurance.

ExecSelect™ is intended to complement an employer's existing health plan while providing meaningful financial protection and peace of mind for eligible participants.

## Development

Clone the repository:

```bash
git clone https://github.com/<organization>/sankatylight.com.git
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```
